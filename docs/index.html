raftkv

A linearizable, hash-partitioned key-value store on Raft in C++20, with a deterministic simulator that runs whole clusters from a seed and checks every history for linearizability.

Source code on GitHub CI runs Design notes What was tested, found, and not found

What it does

  • Raft: leader election, pipelined log replication, snapshots, ReadIndex linearizable reads, CheckQuorum.
  • CRC-checked write-ahead log with torn-tail repair and crash-safe snapshots.
  • put / append / compare-and-swap with exactly-once client sessions; keys hash-partitioned across shards of 3 replicas.
  • gRPC between nodes and clients; group commit (one fsync per batch of requests).

How it is verified

A deterministic simulator runs whole clusters (virtual clock; lost, duplicated and reordered messages; partitions; power loss that tears writes, including mid-fsync; clock skew; leader kills) and an independent checker verifies every history is linearizable. Any failure replays exactly from its seed. The tester is itself tested: it catches 5 of 6 deliberately injected protocol bugs (the sixth is documented as not found).

Measured

Simulation on the final code; real 3-process cluster on a GitHub-hosted 4-vCPU Linux runner (servers and load generator share the machine).
